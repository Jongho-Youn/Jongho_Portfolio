FEATURED BUILD

Time Rouse Pro Max

An alarm clock you can't ignore — a desk robot that verifies you're actually awake before it lets you go back to sleep. Full hardware-to-firmware build.

ESP32 C/C++ (Arduino) I2C MPU6050 IMU SSD1306 OLED PWM / LEDC WiFi + Async Web Server SPIFFS NTP Custom PCB 3D-printed enclosure

A team project where I ended up owning the entire hardware and firmware stack solo — schematic, PCB layout and fabrication, enclosure modeling, and all of the embedded code — while the rest of the team focused on other parts of the project.

  • Sensor fusion wake-verification: the alarm only disarms once PIR motion, a light-level change, an accelerometer tilt, and a sound trigger have all fired — a state machine tracks four independent sensor flags and resets them per cycle.
  • Attitude estimation from raw IMU data: reads the MPU6050 over I2C and computes tilt (roll/pitch) directly from raw accelerometer X/Y/Z with atan2, rather than relying on a library's fused output.
  • Custom OLED face library: wrote a small display driver (maxr.h) on top of Adafruit_GFX to animate eyes — open/close, blink, look-left/right, smile — as the robot's expression layer.
  • On-device web configuration: ESPAsyncWebServer serves a config page for WiFi credentials and alarm time; falls back to its own WiFi AP with a captive setup form if it can't join a network. Settings persist to flash via SPIFFS.
  • Time sync + audio: NTP client keeps the clock accurate; alarm melody and sensor tones are generated in software over an LEDC PWM channel, with a second channel/GPIO trio driving an RGB status LED.
  • From schematic to fabricated board: designed the full schematic and PCB layout (display, IMU, PIR, light and sound sensors, RGB LED, motor and battery headers), then had it manufactured — this is a real, populated board, not a breadboard prototype.
  • Calibrated for the real demo, not a lab bench: thresholds were tuned for reliable operation at the live PoC rather than a formal error-rate target — light threshold set and quantified against a phone flashlight (the same light source used in the demo), tilt handled as a simple angle threshold, and the sound trigger set high enough to hold up in a noisy demo room.
  • Diagnosed a channel conflict: the buzzer output was clashing with another peripheral on the same channel, chopping the audio; traced it to a shared line and fixed it by physically separating the output onto its own path off the battery rail.
  • Three months of iteration: redesigned the enclosure after the fabricated PCB came out larger than the original model allowed for, and went through several passes tuning the OLED eye-blink/close animation to remove stutter — built and tested solo, working nights through most of the build.
Note: team project — 3D modeling, PCB design/fabrication, and all firmware were done solo; teammates worked on other aspects of the project.

LIVE ROBOT TOOLS

ROS Field Tools

Scripts that run directly on the robot rather than on logs after the fact — real-time obstacle monitoring, manual override, and production logging on a live ROS-based AMR fleet.

AMR Clearance Monitor & Teleop

Python · ROS · LaserScan · Twist · termios

Terminal dashboard showing live obstacle clearance in all four directions, doubling as a manual override controller.

  • Converts raw LiDAR range/angle readings into robot-frame clearance (mm) per zone, correcting for the robot's live heading offset from odometry
  • Terminal keyboard teleop (WASD drive, arrow-key speed adjust) publishing straight to cmd_vel
  • Watchdog stop: automatically halts the robot if no key is pressed within the timeout window

Move/Stop Time Logger

Python · ROS · Odometry · CSV

Logs how long the robot is actually moving vs. stopped, from live velocity data.

  • State machine over linear/angular velocity, with a debounce hold-time so momentary noise isn't read as a stop
  • Appends start/stop timestamps and move duration to CSV for uptime and productivity analysis

AP Roaming Monitor

Python · iw · regex

Watches which WiFi access point the robot is actually connected to and flags every handoff in real time.

  • Parses iw dev link output for BSSID and signal strength
  • Maps BSSIDs to human-readable AP names and prints an event the instant the robot roams to a new AP
  • The tool behind the AP-roaming diagnostics work listed under field experience

FIELD TOOLING

Robotics Engineering Toolkit

A suite of Python desktop applications built on the job to speed up AMR fleet diagnostics, mapping validation, and reporting on a 20+ robot production line.

AMR RCA Studio

Python · PySide6 · pyqtgraph · Gemini API

Desktop app for root-cause analysis across five AMR log formats (dhrosout, kern, mcu, nav, ping).

  • Signature-based auto log-type detection; background-threaded archive import (zip / split tar.gz)
  • Builds stop-event RCA by correlating nav position, timing, and an alarm dictionary
  • Node ranking / MTBF stats, timeline playback synced to an XY map view
  • AI-assisted analysis (Gemini) with tool-use for on-demand raw log search

AMR Topo Compare Tool

Python · Tkinter

Diffs robot map (topo.json) packages against a baseline and selectively re-applies changes.

  • Finds topo.json anywhere inside nested ZIPs/folders; auto-expands multi-map packages
  • Diffs node info, prev/next topology, safety zones, speed, and travel direction
  • Maps safety-zone IDs by name across maps (IDs aren't stable between maps)
  • Checkbox-select individual diffs to merge back into a new, validated JSON

Map Score Visualizer

Python · PySide6 · pandas · pyqtgraph

Live-reloading path/score plotter for localization and navigation-quality data.

  • Parses x/y/score triples from raw text logs, computes cumulative path distance
  • Watches the source file and redraws on change; drag-and-drop file loading
  • Synced hover/click highlighting across the path and score plots

Production Cycle Extractor

Python · openpyxl · py7zr

Turns raw AMR position logs (xlsx/zip/7z) into clean, styled cycle-count reports.

  • Rule-based cycle detection: a stop only counts once it's stable for 3+ consecutive rows and the dock has changed since the last count
  • Column-alias matching handles logs with slightly different headers
  • Formatted Excel output in switchable horizontal/vertical layouts

Node Coordinate Extractor

Python · Tkinter · pandas · openpyxl

Pulls node XY coordinates out of one or many topo.json maps and lays them out in Excel however the review needs.

  • Reads topo.json directly or from inside ZIPs; matches nodes by ID or by name
  • Three export layouts — vertical (stacked per file), horizontal (one row per file), and node-XY (one row per node, columns per file) — for comparing the same node across many maps at a glance
  • Natural sort on file names and numeric-aware sort on node IDs so output reads in the order a person expects
